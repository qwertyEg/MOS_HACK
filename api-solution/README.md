# api-solution — мониторинг стройки по фото через GLM

Хакатон ЛЦТ 2026, кейс 07 (ДГП Москвы). Сервис принимает фото с камер
стройплощадки, отправляет их в vision-модель GLM (z.ai) и по ответам
определяет:

- на каком этапе стройка и какие подэтапы идут сейчас;
- готовность объекта в процентах (прогресс-бар) и по каждому этапу;
- технику на площадке, работает она или стоит;
- отклонения «этап → техника» (например, экскаватор работает без самосвалов);
- простои, отставание от календарного плана в днях и прогноз окончания;
- сводку по всей стройке: какая техника была за весь период, что подтверждено
  и когда, — с выгрузкой в CSV.

Модель выбирается в интерфейсе: облачная GLM (z.ai) или локальная (слот
готов, подключение — [docs/local-model.md](docs/local-model.md)).

Интерфейс — Streamlit без стилей: только загрузить фото и посмотреть результат.

## Быстрый старт

```bash
cd api-solution
python3 -m venv .venv && .venv/bin/pip install -r requirements.txt
cp .env.example .env                                   # вписать ZAI_API_KEY
.venv/bin/python tools/smoke.py test_photos/doric_2006_07_17_12_30_24.jpg   # проверить ключ на одном фото
.venv/bin/streamlit run app.py                         # открыть http://localhost:8501
```

В интерфейсе: слева создать объект → вкладка «Загрузка» → выбрать фото →
«Добавить и проанализировать». Результат — на вкладках «Сводка» (этап,
прогресс, график, отклонения), «Стройка» (сводка по всем фото, CSV) и «Кадры»
(разбор каждого фото). Дата съёмки берётся из EXIF или имени файла
(`..._2006_07_17_12_30_24.jpg`), её можно поправить перед анализом.
Календарный план строится сам: от первой до последней даты фото, этапы по
типовым пропорциям; его можно отредактировать или загрузить файлом (вкладка «План»).

Ключ с open.bigmodel.cn, а не с z.ai — поменять `ZAI_BASE_URL` в `.env`.

## Тесты

```bash
.venv/bin/python -m pytest              # 83 теста без модели, бесплатно, ~5 с
.venv/bin/python -m pytest -m live -s   # модель против ручной разметки 10 фото
```

Подробно — [docs/testing.md](docs/testing.md).

## Результат на сегодня

`glm-4.6v` на 10 реальных фото одной стройки (от свай до готового фасада),
с контекстом стройки между кадрами: этап определён верно на **9/10** (точно —
7/10; без контекста — 8/10), ракурс 9/10, лишней техники модель не выдумала
ни разу; ложную историю стройки модель не принимает и отмечает противоречие.
Стоимость **$0.0020 за фото** (~2500 фото на $5). На всю разработку и
тестирование потрачено $0.10.
