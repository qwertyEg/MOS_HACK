# Чек-лист этапов строительства для VLM (GLM)

> Файл сгенерирован `build.py` из `checklist.json` — правки вносить в JSON.

Источник: `Сводный_перечень_строительных_работ_ЛТЦ.xlsx`. Охват: здания (Жильё, Образование, Здравоохранение, Спорт, Культура, Административные здания, ДОУ, Офисно-деловой центр); дороги не входят.

## Как устроено

- **8 макроэтапов** (совпадают с веткой `dev-lamonifi`) → **подэтапы**, к которым привязана каждая строка справочника. Полная раскладка по строкам — `work_map.csv`.
- **Признаки** — общий пул вопросов к модели с ответом `yes / no / unsure`. Этап ссылается на признаки: `must_have` — результат этапа виден, `must_not_have` — противоречит этапу. У подэтапа: `active_when` — работы идут сейчас, `done_when` — результат есть.
- **latching** — признак после подтверждения не пропадает (котлован вырыт — значит был вырыт, даже если сейчас его закрыл кран).
- **Техника**: `ожидается` — без неё этап не движется; `возможна` — не аномалия; `не по этапу` — если работает, поднимаем отклонение. Припаркованная техника в сопоставлении не участвует (PLAN.md §3.9).
- **Прогресс-бар**: общий % = Σ вес этапа × прогресс этапа; прогресс этапа = Σ вес подэтапа × (1 — готов, доля по метрике или 0.5 — идёт, 0 — не начат). Учитываются только работы, видимые снаружи; внутренние идут параллельно фасаду и в % не входят.

## 1. Подготовка территории — вес 5%

Снос, вырубка, вынос сетей, огораживание и развёртывание площадки. Этап закончен, когда площадка огорожена, расчищена и на ней стоит бытовой городок.

- **Должно быть видно:** `fence`, `cabins`, `cleared`
- **Не должно быть:** `pit`, `above_grade`
- **Техника ожидается:** Экскаватор, Самосвал, Бульдозер, Фронтальный погрузчик, Кран-манипулятор
- **Техника возможна:** Автокран, Грузовик (бортовой, длинномер, трал), Экскаватор-погрузчик, Каток
- **Техника не по этапу:** Башенный кран, Автобетононасос, Асфальтоукладчик, Строительный подъёмник / фасадная люлька
- **Метрика прогресса:** доля завершённых подэтапов; для 1.1 — доля пятна застройки, свободная от старых построек

### 1.1. Снос и демонтаж существующих строений, вывоз мусора — 35% этапа

Частично разрушенное здание, экскаватор с гидромолотом или ножницами на стреле, груды бетонного боя и арматуры, самосвалы под погрузкой, поливка водой от пыли.

- Работы идут: `old_building`, `debris`; результат есть: `cleared`
- Характерная техника: Экскаватор, Самосвал, Фронтальный погрузчик, Бульдозер
- Строки справочника (4): 10.3. Снос домов в пятне застройки; 10.4. Снос нежилых объектов в пятне застройки; 10.8. Демонтаж ж/б перекрытий; 10.9. Погрузка строительного мусора

### 1.2. Вырубка и пересадка зелёных насаждений — 15% этапа

Пни, поваленные стволы, кучи веток, деревья с обвязанным комом земли для пересадки, манипулятор грузит брёвна.

- Работы идут: `tree_felling`; результат есть: `cleared`
- Характерная техника: Экскаватор, Кран-манипулятор, Грузовик (бортовой, длинномер, трал), Фронтальный погрузчик
- Строки справочника (2): 10.5. Вырубка зеленых насаждений; 10.6. Пересадка зеленых насождений

### 1.3. Вынос инженерных сетей из пятна застройки — 20% этапа

Узкие длинные траншеи по краю или вне пятна застройки, укладка труб большого диаметра, колодцы, кабельные барабаны. Отличить от наружных сетей этапа 8 можно по времени: здесь здания ещё нет.

- Работы идут: `utility_trench`, `pipes_stock`; результат есть: —
- Характерная техника: Экскаватор, Кран-манипулятор, Автокран, Самосвал, Экскаватор-погрузчик
- Строки справочника (13): 10.2. Вынос инженерных систем из пятна застройки (ЦТП/ТП/сети); · Вынос сетей: теплосеть (ЦТП); · Вынос сетей: теплосеть (сети); · Вынос сетей: теплосеть; · Вынос сетей: водоснабжение; · Вынос сетей: Х/Б канализация; · Вынос сетей: ливневая канализация; · Вынос сетей: газоснабжение; · Вынос сетей: электроснабжение (ТП); · Вынос сетей: электроснабжение (сети); · Вынос сетей: электроснабжение; · Вынос сетей: сети связи (КП МПТЦ); · Вынос сетей: сети связи

### 1.4. Обустройство стройплощадки и организация движения — 30% этапа

Сплошной забор по периметру, ворота и КПП, мойка колёс, бытовой городок из контейнеров, временные дороги из плит, временное освещение, дорожные знаки объезда у въезда.

- Работы идут: `temp_road`, `gate_checkpoint`; результат есть: `fence`, `cabins`, `gate_checkpoint`
- Характерная техника: Кран-манипулятор, Автокран, Грузовик (бортовой, длинномер, трал), Бульдозер, Каток
- Строки справочника (2): 10.11. Обустройство строительной площадки; 10.12. Организация движения согласно ПОДД на период строительства

**Метрики этапа**

| Метрика | Ед. | Как считаем |
|---|---|---|
| Доля снесённых построек | % | доля площади пятна без old_building относительно первого кадра |
| Рейсы вывоза мусора | рейсов/день | число появлений гружёных самосвалов у зоны погрузки |
| Площадка развёрнута | да/нет | fence + gate_checkpoint + cabins подтверждены 3 дня подряд |

**Отклонения**

| Условие | Предупреждение | Уровень |
|---|---|---|
| old_building = yes И нет работающих excavator 3 рабочих дня подряд | Снос остановлен | warning |
| debris = yes И excavator работает И нет dump_truck за день | Мусор не вывозится — площадка захламляется, темп сноса упадёт | warning |
| по плану этап 1 закончен, а fence или cabins = no | Площадка не развёрнута к плановой дате | critical |

## 2. Ограждение котлована, шпунт, сваи — вес 8%

Всё, что погружается в грунт до или вместе с разработкой котлована: шпунт, стена в грунте, буросекущие и буронабивные сваи, обвязочная балка.

- **Должно быть видно:** `rig`, `sheet_pile`, `pile_heads`
- **Не должно быть:** `above_grade`
- **Техника ожидается:** Буровая установка, Копёр / вибропогружатель, Гусеничный кран, Автокран, Автобетоносмеситель
- **Техника возможна:** Экскаватор, Грузовик (бортовой, длинномер, трал), Самосвал, Фронтальный погрузчик
- **Техника не по этапу:** Асфальтоукладчик, Каток, Строительный подъёмник / фасадная люлька, Автобетононасос
- **Метрика прогресса:** число погружённых свай / шпунтин относительно проектного (вводится оператором); без проекта — доля периметра котлована с ограждением

### 2.1. Шпунтовое ограждение котлована — 30% этапа

Гофрированная стенка из стальных шпунтин по контуру будущего котлована, пачки шпунта на земле, вибропогружатель на стреле крана или экскаватора.

- Работы идут: `pile_stock`, `rig`; результат есть: `sheet_pile`
- Характерная техника: Копёр / вибропогружатель, Гусеничный кран, Автокран, Экскаватор, Грузовик (бортовой, длинномер, трал)
- Строки справочника (3): 12.3.6. Устройство ограждающих конструкций котлована; · Шпунтовое ограждение; · Устройство шпунтового ограждения котлована, устройство деревянной забирки

### 2.2. Стена в грунте, буросекущие сваи — 30% этапа

Буровая установка с высокой мачтой идёт вдоль контура котлована, длинные трубчатые арматурные каркасы, бетонирование скважин из миксера, бетонная направляющая траншея.

- Работы идут: `rig`, `pile_stock`, `rebar`; результат есть: `pile_heads`
- Характерная техника: Буровая установка, Гусеничный кран, Автобетоносмеситель, Экскаватор
- Типы объектов: Образование, Здравоохранение, Спорт, Культура, Административные здания, ДОУ, Офисно-деловой центр
- Строки справочника (2): 12.3.5. Ограждающие конструкции (СВГ,БСС); · Устройство скважины интервала (бурение, разработка, погружение каркаса, бетонирование)

### 2.3. Сваи фундамента (буронабивные, буроинъекционные, забивные) — 25% этапа

Сваи по сетке внутри пятна застройки (не по контуру), штабели ж/б свай, ряды оголовков с выпусками арматуры.

- Работы идут: `rig`, `pile_stock`; результат есть: `pile_heads`
- Характерная техника: Буровая установка, Копёр / вибропогружатель, Автобетоносмеситель, Автокран
- Строки справочника (3): · Устройство свайного фундамента (при необходимости); · Буронабивные сваи; · Буроинъекционные сваи

### 2.4. Обвязочная балка, закрепление грунтов — 15% этапа

Бетонный пояс поверх свай или шпунта по контуру, опалубка и арматура этого пояса.

- Работы идут: `formwork`, `rebar`; результат есть: `capping_beam`
- Характерная техника: Автобетоносмеситель, Автобетононасос, Экскаватор, Буровая установка
- Типы объектов: Образование, Здравоохранение, Спорт, Культура, Административные здания, ДОУ, Офисно-деловой центр
- Строки справочника (2): · Закрепление грунтов; · Обвязочная балка

**Метрики этапа**

| Метрика | Ед. | Как считаем |
|---|---|---|
| Погружено свай / шпунтин | шт. | подсчёт оголовков на верхнем ракурсе; прирост между днями |
| Темп погружения | шт./активный день | прирост piles_count / активные дни |
| Буровых установок в работе | шт. | drilling_rig + pile_driver со статусом working |
| Доля периметра с ограждением | % | оценка по верхнему ракурсу |

**Отклонения**

| Условие | Предупреждение | Уровень |
|---|---|---|
| drilling_rig присутствует И нет concrete_mixer за день, на котором бурят буронабивные сваи | Скважины не бетонируются — риск обрушения стенок и простоя буровой | warning |
| drilling_rig / pile_driver неподвижна 3 рабочих дня | Свайные работы стоят, техника на площадке простаивает | warning |
| по плану этап идёт, но за 5 дней нет ни одного кадра с rig | Отсутствует основная техника этапа | critical |

## 3. Земляные работы, котлован — вес 7%

Разработка и вывоз грунта, крепление стенок, подготовка дна. Этап закончен, когда дно выровнено и на нём начинается бетонная подготовка.

- **Должно быть видно:** `pit`, `soil_pile`, `earthwork`
- **Не должно быть:** `above_grade`
- **Техника ожидается:** Экскаватор, Самосвал
- **Техника возможна:** Бульдозер, Фронтальный погрузчик, Каток, Автокран, Экскаватор-погрузчик
- **Техника не по этапу:** Асфальтоукладчик, Строительный подъёмник / фасадная люлька, Автобетононасос
- **Метрика прогресса:** доля площади пятна застройки, вскрытая до проектной отметки; прокси — pit_area_pct и число ярусов распорок

### 3.1. Разработка и вывоз грунта — 60% этапа

Экскаватор в котловане или на его бровке грузит грунт в самосвалы, отвалы грунта, съезд-пандус в котлован, колеи.

- Работы идут: `earthwork`, `soil_pile`; результат есть: `pit`
- Характерная техника: Экскаватор, Самосвал, Бульдозер, Фронтальный погрузчик
- Строки справочника (4): 12.3.1. Устройство котлована; 12.3.7. Земляные работы; · Разработка грунта; · Выемка грунта котлована

### 3.2. Разработка грунта с креплением стенок (распорная система) — 20% этапа

Металлические трубы-распорки поперёк котлована или подкосы от стенки ко дну, ярусная разработка — грунт снимают слоями между ярусами распорок.

- Работы идут: `struts`, `earthwork`; результат есть: `struts`
- Характерная техника: Экскаватор, Автокран, Гусеничный кран, Грузовик (бортовой, длинномер, трал)
- Строки справочника (2): · Распорная система; · Разработка грунта с креплением котлована

### 3.3. Планировка и уплотнение дна, песчаное основание — 20% этапа

Ровное дно котлована, отсыпка песка или щебня, каток или виброплита на дне, геодезисты с нивелиром.

- Работы идут: `pit_bottom_prepared`; результат есть: `pit_bottom_prepared`
- Характерная техника: Бульдозер, Каток, Фронтальный погрузчик, Самосвал
- Строки справочника (3): · Планировка грунта; · Уплотнение грунта; · Песчаное основание

**Метрики этапа**

| Метрика | Ед. | Как считаем |
|---|---|---|
| Площадь вскрытого котлована | % пятна | pit_area_pct на верхнем ракурсе, максимум за день |
| Рейсы самосвалов | рейсов/день | число уникальных появлений гружёных самосвалов; прокси объёма вывоза |
| Самосвалов на экскаватор | отношение | dump_truck / excavator(working) в кадре; норма 3–5 при вывозе на 10–20 км |
| Машино-часы экскаваторов | ч/день | см. equipment_hours |

**Отклонения**

| Условие | Предупреждение | Уровень |
|---|---|---|
| excavator working И dump_truck = 0 на кадрах дня | Экскаватор работает без самосвалов — вывоз грунта не обеспечен, темп разработки котлована снизится | warning |
| dump_truck присутствуют И нет работающего excavator / wheel_loader | Самосвалы простаивают — нет погрузки | info |
| trucks_per_excavator < 2 три дня подряд | Нехватка самосвалов — экскаватор простаивает между рейсами | warning |
| pit_area_share не растёт 5 активных дней при присутствии excavator | Техника есть, прогресса нет — вероятна стоянка в ожидании вывоза | warning |
| asphalt_paver или roller на дне котлована | Техника не соответствует этапу | info |

## 4. Монолит подземной части — вес 12%

Подготовка, фундаментная плита, стены и перекрытия подземных этажей, гидроизоляция, обратная засыпка пазух. Этап закончен, когда выполнено перекрытие на отметке 0 и пазухи засыпаны.

- **Должно быть видно:** `formwork`, `rebar`, `slab`, `below_grade`
- **Не должно быть:** `above_grade`
- **Техника ожидается:** Автобетоносмеситель, Автобетононасос, Башенный кран
- **Техника возможна:** Автокран, Грузовик (бортовой, длинномер, трал), Кран-манипулятор, Экскаватор, Бульдозер, Каток
- **Техника не по этапу:** Асфальтоукладчик, Строительный подъёмник / фасадная люлька, Копёр / вибропогружатель
- **Метрика прогресса:** доля забетонированной фундаментной плиты (по захваткам) → число готовых подземных уровней → засыпка пазух

### 4.1. Подготовка под плиту, фундамент под башенный кран — 10% этапа

Тонкий слой бетона (бетонная подготовка) на дне котлована, отдельный бетонный куб-фундамент под будущий башенный кран.

- Работы идут: `pit_bottom_prepared`, `concrete_pour`; результат есть: `pit_bottom_prepared`

## 5. Монолит надземной части — вес 35%

## 8. Наружные сети и благоустройство — вес 10%

Наружные инженерные сети вокруг здания, вертикальная планировка, проезды и тротуары, озеленение, МАФ, освещение и постоянное ограждение. Конец — снятие строительного забора.

- **Должно быть видно:** `paving`, `landscaping`, `amenities`
- **Не должно быть:** `bare_ground`
- **Техника ожидается:** Экскаватор, Самосвал, Каток, Фронтальный погрузчик, Асфальтоукладчик
- **Техника возможна:** Автогрейдер, Бульдозер, Мини-погрузчик, Экскаватор-погрузчик, Кран-манипулятор, Автокран, Грузовик (бортовой, длинномер, трал)
- **Техника не по этапу:** Копёр / вибропогружатель, Буровая установка, Автобетононасос, Башенный кран
- **Метрика прогресса:** доля благоустроенной площади двора (покрытие + озеленение) на верхнем ракурсе; до начала покрытий — по подэтапам 8.1–8.2

### 8.1. Наружные инженерные сети — 25% этапа

Траншеи вокруг готового здания, укладка труб и кабелей, бетонные колодцы, засыпка песком. Отличие от 1.3 — здание уже стоит.

- Работы идут: `utility_trench`, `pipes_stock`; результат есть: —
- Характерная техника: Экскаватор, Экскаватор-погрузчик, Кран-манипулятор, Самосвал, Автокран
- *Примечание:* В dev-lamonifi раздел 12.5 целиком помечен как невидимый. Наружные сети с камеры видны (траншеи у здания), поэтому 12.5.1 вынесен сюда; 12.5.2 (внутренние сети) остаётся невидимым.
- Строки справочника (9): 12.5.1. Устройство наружных сетей; · Теплосеть; · Водоснабжение; · Х/Б канализация; · Ливневая канализация; · Электроснабжение; · Слаботочные сети; · Дизель-генераторная установка, в т.ч. фундамент под оборудование; · Наружные сети связи

### 8.2. Вертикальная планировка — 15% этапа

Разравнивание территории вокруг здания, подсыпка песка и щебня, уплотнение катком, подпорные стенки на перепадах рельефа.

- Работы идут: `grading`; результат есть: —
- Характерная техника: Бульдозер, Автогрейдер, Каток, Самосвал, Фронтальный погрузчик
- Строки справочника (4): · Устройство подпорных стен; 12.7.4. Вертикальная планировка; · Устройство насыпи; · Устройство выемки

### 8.3. Проезды, тротуары, отмостка — 30% этапа

Бордюры вдоль будущих проездов, щебёночное основание, асфальтоукладчик с катком, укладка плитки, бетонная отмостка по периметру здания, разметка.

- Работы идут: `curbs`, `asphalt_work`; результат есть: `paving`
- Характерная техника: Асфальтоукладчик, Каток, Самосвал, Мини-погрузчик, Автогрейдер
- Строки справочника (8): 12.7.1. Устройство проездов и тротуаров; · Устройство асфальтобетонного покрытия проездов, тротуаров, площадок с установкой бортового камня; · Устройство покрытий из тротуарной плитки с установкой бортового камня; · Устройство бетонных покрытий (отмостка); · Устройство площадок с покрытием из резиновой крошки; · Установка водоотводных лотков; · Обустройство дорог: установка знаков, нанесение разметки; 12.7.7. Устройство пешеходных зон и тротуаров

### 8.4. Озеленение и малые архитектурные формы — 20% этапа

Раскатка рулонного газона, посадка деревьев с растяжками, клумбы, детские и спортивные площадки, скамейки, урны.

- Работы идут: `landscaping`, `amenities`; результат есть: `landscaping`, `amenities`
- Характерная техника: Мини-погрузчик, Кран-манипулятор, Грузовик (бортовой, длинномер, трал), Фронтальный погрузчик
- Строки справочника (8): 12.7.2. Озеленение; · Устройство газона рулонного; · Устройство газона посевного; · Устройство цветников; · Посадка деревьев; · Посадка кустарников; 12.7.3. Установка МАФов; 12.7.5. Посадка зеленых насаждений

### 8.5. Наружное освещение, ограждение территории — 10% этапа

Фонарные опоры вдоль проездов, лёгкий постоянный забор с калитками и шлагбаумами, подсветка фасада. Строительный забор демонтируют — признак завершения объекта.

## Общие метрики площадки

| Метрика | Ед. | Как считаем |
|---|---|---|
| Состав техники | шт. по типам | медиана по кадрам дня для каждого типа; максимум за день как пиковое присутствие |
| Доля работающей техники | % | единиц в статусе working / всех присутствующих, по дню |
| Машино-часы по типам | ч | число кадров со статусом working × интервал между кадрами |
| Рабочие на площадке | чел. | медиана workers_count по дневным кадрам |
| Активные дни | дни | день активный, если хотя бы на двух кадрах есть работающая техника или рабочие; ночные кадры тоже учитываются |
| Дни простоя | дни | рабочий по календарю день без признаков активности; отдельно — текущая серия простоя подряд |
| Техника есть, работ нет | дни | дни, когда техника этапа присутствует, но вся неподвижна (PLAN.md §3.9, сигнал EQUIPMENT_PARKED_ONLY) |
| Прогресс этапа | % | по подэтапам: done = 1, in_progress = доля по метрике этапа или 0.5 |
| Общий прогресс объекта | % | Σ weight этапа × прогресс этапа; учитываются только наблюдаемые с улицы работы |
| Отклонение от графика | дни | фактическая дата начала/окончания этапа минус плановая; знак — опережение или отставание |
| Темп этапа | ед. метрики / активный день | прирост метрики прогресса этапа, делённый на активные дни (PLAN.md §3.8, уровень 2) |
| Прогноз окончания этапа | дата | остаток метрики / темп в активных днях × доля активных дней за последние 2 недели |
